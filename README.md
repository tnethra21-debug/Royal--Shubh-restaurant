# Royal Shubh — Luxury Indian Fine Dining

Welcome to the official repository of **Royal Shubh**, a world-class luxury Indian fine dining digital experience. 

Structured with pristine typography, a high-contrast warm palette, glassmorphism overlays, and smooth layout entry transitions, this responsive Single-Page Application (SPA) mirrors the experience of stepping into a multi-award-winning Michelin-starred restaurant.

---

## 🎨 Visual Philosophy & Aesthetic Blueprint

* **Cosmic Obsidian & Imperial Gold Palette**: Styled intentionally using deep background levels (`#0B0B0B`) to establish a dramatic, eye-safe twilight stage, paired with fine brushed gold borders (`#D4AF37`) and ivory table-cloth accents (`#F8F5F0`).
* **Sartorial Typography**: Pairs spacious, elegant display serifs for headings with high-legibility sans-serif metrics for sensory descriptions and clean `JetBrains Mono` values for administrative elements (such as hours and phone indices).
* **Atmospheric Glassmorphism**: Cards and navigation rails utilize high-contrast translucent blurs and glowing gold hover highlights to suggest high-end, clean crystal glassware.

---

## 🍽️ Key Functional Modules

1. **Cinematic Hero Entry**: Immersive full-screen background with a parallax title sequence and quick call-to-action anchors.
2. **The Sovereign Story (About)**: Interactive historical narrative highlighting ancient culinary lineages and exquisite interior architecture.
3. **Curated Culinary Menus**: Dynamically category-filtered boards highlighting gold-gilded, chef-recommended signature delicacies.
4. **Master Chef Spotlight**: Interactive biographies showcasing the culinary artisans and their heritage techniques.
5. **Luxury Media Gallery**: A rich interactive media drawer featuring high-definition imagery of authentic plate styling, imperial vaults, and traditional handwashing rituals.
6. **Sovereign Reservation Portal**: Seamless serverless dining request interface equipped with live client-side validation, guest counts, and special culinary request boards.
7. **Interactive Map & Imperial Hours**: Clean responsive guides highlighting weekly operational schedules, contact indices, and real-time physical direction assets.

## 🚀 Tech Stack

* **Core Runtime**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Engine**: [Vite 6](https://vite.dev/) (Pre-configured with zero HMR-flicker policies)
* **Styling Framework**: [Tailwind CSS v4](https://tailwindcss.com/)
* **Animations**: [Motion](https://motion.dev/) (Declarative page transitions and layout state animations)
* **Icons**: [Lucide React](https://lucide.dev/) (Crisp, light vector icons)

## ⚙️ Local Development Settings

To run **Royal Shubh** locally on your workstation, follow these rapid setup steps:

### Prerequisites
* **Node.js** (v18.0 or newer recommended)
* **npm** or **yarn**

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/royal-shubh.git
cd royal-shubh
```

### 2. Install Project Dependencies
```bash
npm install
```

### 3. Spin Up Development Server
```bash
npm run dev
```
*Your luxury application is now running live locally at `http://localhost:3000` (or the fallback local address printed in your terminal).*

### 4. Create Production Build
```bash
npm run build
```
*This compiles optimized asset bundles into the static `/dist` folder, fully prepared for Cloud Run, Vercel, Netlify, or standard Amazon S3 deployment.*
